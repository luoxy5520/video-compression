# 直接回放消融与残差校正结果

8 条独立测试视频，`sample_0024–0031`，分别为旗帜和舞者两个 prompt，各含 4 个 seed。下表是 P 帧亮度 PSNR 和整段码率的逐视频均值。所有方案固定 QP 28，码率随状态变化。

| 方案 | Y PSNR (dB) | 码率 (kb/s) |
| --- | ---: | ---: |
| 历史 step 20 | 20.93 | 197.22 |
| 仅换模式 | 20.86 | 218.04 |
| 仅换 MV | 24.53 | 244.51 |
| 新模式/MV + 旧残差 | 25.16 | 280.06 |
| 新模式/MV + 代理减实际 MC | 39.57 | 1397.39 |
| 新模式/MV + 学习残差校正 | 39.57 | 1397.39 |
| 新模式/MV + 真值源减实际 MC（诊断） | 39.58 | 1397.75 |
| 全 P16 + 同一候选 MV + 代理减实际 MC（诊断） | 40.31 | 1499.23 |

固定旧残差时，替换两项提升 4.23 dB，码率增加 42.0%。单换 MV 提升 3.61 dB，单换模式略降 0.07 dB。8 条历史基线码流逐字节复现。固定残差的 32 条码流在 MV 同步修复前后逐字节一致。

旧 B1 回放恢复写码流的 MV 缓冲区，运动补偿读取的缓冲区没有同步。由此产生的编码端参考漂移使旧后端的代理残差结果只有 22.26 dB。修复后 P16 使用写入码流的选中 MV，Skip 使用 JM 的原生派生，全部 48 条主测试和 16 条诊断码流均通过编码器、JM 解码器、FFmpeg 的重建一致性检查。

在修复后的参考上，学习校正把验证集亮度残差 RMSE 从 0.4533 降到 0.4453 像素。该幅度没有改变实际量化输出，8 条测试码流与简单代理差分逐字节一致。与真值源诊断相比，代理差分只低约 0.007 dB。全 P16 对照比固定新模式高约 0.74 dB，码率增加约 7.3%。后续可在验证集上比较基于实际参考的 Skip 门控与直接分类，按码率和重建误差联合选择阈值。
