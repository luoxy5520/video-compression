# G0–G2 统一输入条件对照

G0 输入冻结的末层 hidden 特征。G1 加冻结 A 的 Mode/MV。G2 再加 A 轨迹上一帧重建亮度，每宏块保留 4×4 个均值。G2 的缓存来自可生成的 A 参考，本轮作为离线诊断条件。独立在线取参考、全链路延迟和显存尚无验收。G0/G1 的头部及码流回放没有源、教师或参考帧推理输入。冻结 A 的模式、原生 MV 和 Oracle I 是所有组的共同条件，G0 的 P16 合法性掩码由回放状态提供。

所有组均有 81,383 个可训练参数。未启用的输入通道置零，使用同一头、AdamW、12 epoch、两种子、44/16 划分和 64 个位置预算。C 读 DC 与两个第一低频有符号 QP28 系数，R 读 4×4 残差均值。标签使用冻结 A 自身参考上的真实源减原生 qpel MC，避免教师参考混入条件。每视频预定 8,192 个 P16 位置作为固定探针。值损失还纳入训练大残差支持点，位置损失使用最难负例。C/R 分别实际回放，舍弃幅值小于 2 的输出。

G0–G2 都满足逐视频 +3% 上限。G0 的种子与输出目标之间，极小的回放收益方向翻转。G1 的显式 Mode/MV 未给出稳定增量。G2 的 R RMSE 比同种子 G1 分别低约 0.019 和 0.010 个像素级单位，C 的 MAE 无同步改善，真实回放也无稳定收益。各组符号平衡准确率均低于 2%，主要受输出量化为零限制。完整逐视频配对见 [paired_validation.csv](paired_validation.csv)。逐帧、训练历史、开销、支持精度和语法比特见[归档](https://github.com/luoxy5520/video-compression/tree/artifacts/p2-infoprobe-20261108)。
