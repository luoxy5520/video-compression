# G3–G5 条件触发结果

G0–G2 在符号读出和真实回放上都接近退化输出，尚不足以区分特征来源。本轮触发小规模 G3/G4。固定训练和验证各 4 条，每个 split 取前四个不同 prompt 的第一条，G1 同样重训作为配对对照。各头 81,383 个可训参数，沿用两种子、优化器、12 epoch、标签、固定位置、实际回放和 64 个位置预算。此子集与 16 条验证的均值分开解读。

G3 使用 step 20 clean latent，2×2 空间重排成 64 通道，走相同冻结 A 主干的后续时空映射。G4 使用同一输入视频、采样步、prompt、seed 和 conditional 分支的第 14 个零基 DiT block。8 条重新提取的末层张量与历史缓存逐元素相等，中间层形状为 [1,7800,1536]，复用 5×30×52 token 重排和 A 的冻结投影。冻结投影本来由末层训练，因此层间结论受投影适配限制。
