# P2-GeneralizationProbe 阶段判定

**保留冻结 A。** 同 prompt 换 seed 后，精确稀疏系数的实际写入召回没有稳定泛化。统一降维后，原始 hidden 在匹配候选的近邻读出上有优势，优势取决于读出方式。区域残差能量比精确位置和低频系数幅值更适合本轮跨视频诊断。没有独立学生通过回放门槛，未启动新学生 JM。最终盲测封存，P3、G5 和 44 条大模型训练未启动。

## GZ0｜同 prompt 不同 seed 能否泛化？

**固定 C1 能记住这八条视频，但同 prompt 新 seed 的精确位置未稳定泛化。** GZ0 在训练池内使用历史 T0 监督。每折 8 条训练视频，每条 400 次曝光，固定两种子、架构与损失。每帧选 4 个块的最高频率，再用历史幅值过滤。AP 是全合法候选的平均精度，写入召回以每条 64 点为分母。

| C1 | A 拟合 | B 同 prompt 新 seed | C 运动近域 | D 跨 prompt |
| --- | ---: | ---: | ---: | ---: |
| 折 0 / 1701 | 97.852% | 0.065% | 0.260% | 0.260% |
| 折 0 / 1702 | 95.313% | 0.000% | 0.130% | 0.130% |
| 折 1 / 1701 | 95.898% | 0.260% | 0.391% | 0.391% |
| 折 1 / 1702 | 96.094% | 0.391% | 0.781% | 0.781% |

小头 A 的同 prompt 写入召回为 0.065%–0.391%。B 的随机期望为 0.0031%–0.0048%，支持折空间先验为 0–0.0651%。部分运行超出机会水平，全候选 AP 也高于先验，但绝对 AP 和写入命中都很低。同 prompt 四次 C1 写入召回的逐视频 bootstrap 95% CI 依次为 [0, 0.195]、[0, 0]、[0.065, 0.521]、[0.130, 0.716]，单位均为百分点。B 在四次 C1 中均低于 D。B/D 的视频内容与掩码大小仍有差别，折间查询也有重叠，不能把这组差值解释为跨场景比同场景更容易。预先定义的运动近域规则将全部跨 prompt 样本纳入 C，远域对照为空。保留 C/D 重合这一限制，不事后调整划分。

## GZ1｜原始 DiT hidden 是否更可读？

**统一读取器下，原始 hidden 保留了更多可供近邻读取的稀疏位置线索。** 使用同一 T0、P16 候选和匹配运动、4×4 块位置、频率的抽样，每个正例配至多 16 个负例并去重。F0、F1、F2 各在支持视频拟合 PCA32、尺度、线性读出和近邻索引。三个臂均附加 A 的两维 MV 与帧组内相位，线性位置探针另用相同的支持折匹配先验。主要结果按查询视频等权，置信区间按视频配对 bootstrap。

| 臂 | 原始形状和对齐 |
| --- | --- |
| F0 | 冻结 step-20 缓存 [1,67,16,30,52]。取 64 个编码通道，使用冻结头的原生时序卷积和 4 相位展开，重用同一 A MV。 |
| F1 | step-20 conditional 最终层 [1,7800,1536]。按历史 token 排列解为 5×30×52。每个 token 对应一宏块，跳过 I 对应的时间索引 0，每组四个 P 帧复制一份特征。 |
| F2 | 生成过程 clean latent [16,5,60,104]。将宏块对应的 2×2 latent 空间格拼为 64 维，时间分配同 F1。 |
| F3 | 历史中间层缓存只覆盖本训练池的 4 条，无法完成相同两折。未新采集。 |

本轮未增加插值、填充或显式位置编码。F1 含 DiT 已计算的上下文，并且四帧组内没有 F0 的学习式相位展开。原始缓存每宏块 1536 通道，约为 F0 编码通道的 24 倍，统一读出为 35 维加线性先验项。GZ1 主比较 CPU 总墙钟约 17 秒。完整宽度敏感性约 18 秒，F0 保留历史 67 维宏块向量并做 L2 cosine；F1 及 F2 使用相同 MV 与 P16 常数，线性读取对原生输入做支持集标准化。

同 prompt 两折的 kNN AP，F0 为 **9.28% / 9.58%**，F1 为 **13.66% / 11.42%**。配对提升分别为 +4.38 [+2.64, +6.41] 和 +1.84 [+0.77, +2.80] 个百分点。Top-1 正类召回由 **11.13% / 13.82%** 提升到 **19.32% / 18.70%**，两折差值区间均为正。跨 prompt 的匹配 kNN AP 也提高。线性 AP 方向一致，但 F1−F0 的区间跨零。原生宽度下，F1 的 kNN AP 仍高于 F0，Top-1 正类召回却在两折两组都低于 F0。匹配采样 AP 不能与 GZ0 的全候选 AP 相比。结果支持对齐和读出影响可读性，未建立原始 hidden 对所有读出、标签及输入空间的稳定优势，也未量化部署资源或新学生收益。

## GZ2｜哪种目标更适合跨视频学习？

**宏块级区域能量的跨视频证据最稳定。** 三类目标使用同一冻结 A 解码轨迹、A MV 与 P16 候选。重新生成的稀疏标签与 44 条历史 T1 逐元素相同。真实源只用于构造离线标签。

- **Z1 精确稀疏位置**。对照 T0 教师参考与 T1 冻结 A 参考，平均每视频只重合 **16.23/64** 点，宏平均 IoU **0.150**。重合点符号一致率 **100%**，平均 level 绝对误差 **1.67**。相同轨迹的 T1 匹配样本仍有部分线索，例如 F0 线性 AP 高于匹配先验。它衡量的是降采样后的读出。GZ0 已用全候选测得实际写入泛化很弱。两种结果衡量不同难度。
- **Z2 区域能量**。每视频从合法 P16 中固定抽取 1,024 个宏块，标签为 16×16 luma 残差的均方。线性读出拟合 log1p 能量，评价恢复原尺度后的误差与 top 10% 召回。F0 同 prompt 两折 top 区域召回 **44.2% / 41.1%**，训练运动先验 **12.2% / 8.7%**，配对提升的 95% CI 分别为 **+27.6～+36.1** 和 **+27.7～+37.0** 个百分点。跨 prompt 为 **31.0% / 43.6%**，也稳定超过先验。F0 的 Spearman 跨组为 **0.60–0.72**。F1 的同 prompt 区域召回约 **44%**，区域任务未显示 F1 的一致优势。
- **Z3 低频连续系数**。沿用 JM 相容的 4×4 luma 整数变换，评估栅格频率 0、1、4，近零绝对值阈值为 16、24、24。三臂线性和近邻的幅值 MAE 均未低于零预测。结果包含非近零符号一致率和 QP28 后非零变化，不能由区域能量结果推断精确系数可预测。
- **Z4** 缺少核验过的逐候选真实增量码率，未运行。

## 证据等级与闭环决策

- **证据支持**。在固定 F0 头和 T0 协议下，精确位置泛化失败已出现在同 prompt 的独立视频。容量足以拟合支持视频，场景变化无法独自解释失败。实际参考轨迹的变化会改变选中的稀疏位置，区域能量在新视频上更容易读取。
- **仅推测**。实例特异的残差、参考轨迹敏感性、粗时序对齐和读取器偏置可能共同造成失败。GZ1 的匹配结果支持投影或对齐过程中丢失部分可读线索，无法拆分两者。
- **未验证**。没有证明 DiT hidden 信息不足，也没有检验区域预算策略的闭环净收益。既定统计门槛未选出合格独立学生，未进行新学生 JM、候选码率或尾帧验收。训练阶段 GPU peak allocated 含预加载缓存，8 个 GZ0 运行各约 21–29 秒、1.84–2.21 GiB。头部评估开销见逐视频科研归档。
- **下一阶段**。暂停继续扩大 hidden-only sparse head，保留冻结 A。区域重要度或预算分配有独立诊断依据，需另立受控实验才能判断闭环收益。
