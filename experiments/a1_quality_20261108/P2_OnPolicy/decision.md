# P2-OnPolicy 阶段判定

**继续使用冻结 A。** T1 未满足两个种子同时超过 A 并相对 T0 取得可辨配对收益的联合门槛。O2 未启动，P3 保持停用，最终盲测封存。T1 相对 T0 的真实回放结果为两个种子均未改善，具体见配对表。

O0 固定了正样本数，T0/T1 每条都是 64 个 Y 系数。两组固定样本可以拟合，验证集上的位置命中和真位置整数精确率仍低。O3 在每 prompt 一条验证视频上以学生实际解码参考重算标签，离线测真位置值读出和预测位置的目标幅值；完整数据见科研归档。诊断过程未更新权重。学生参考对 A 的逐帧 Y-MSE、逐帧 PSNR、语法 bits 与三方帧哈希均有保存。四个正式学生从原始 hidden 重新导出，所选样本的 Mode、MV、Y/U/V 与评分状态逐项相同。

H1 的标签参考敏感性成立，改为 A 参考的监督收益以配对结果为限。H2 中的跨视频位置和值读出仍是实际瓶颈，尚未区分特征可读性和现有头的泛化能力。H3 只观察了学生参考偏移，本轮没有进行训练干预。下一步若另立实验，先在实际学生参考上验证候选区域或符号能否独立泛化，再考虑更换输入表示。
