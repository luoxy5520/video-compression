# 锁定协议

[机器可读配置](configs/locked.json)。O0 同一来源、同一选择器、同 64 个点，仅替换重建参考。O1 使用困难负例排序、符号 BCE、幅度交叉熵。两臂相同 67 通道冻结输入、16 频率、AdamW 0.001、每次一条视频，12 个 epoch，每种子 528 次更新，固定样本 400 次更新。

预注册门槛为两种子 P 帧及末四帧均优于 A，平均和逐条码率上限 +3%，最差视频不低于 −0.30 dB。T1−T0 的配对收益也须有意义。按视频在 prompt 内 bootstrap，四个 prompt 等权。最终盲测、P3 保持封存，O2 未获触发。
