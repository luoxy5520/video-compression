# O0｜只替换参考轨迹

先在训练样本 0000 和 0004 独立重算标签并核对重复文件 SHA-256，再扩至 44 train / 16 val。T0 的参考来自 P0.6 offline_gain_3 原始码流，T1 来自冻结 A。60 条历史教师码流从已保存状态重放，匹配原 SHA，并与 A 核对原生 Mode/MV。P0.6 旧教师使用实际比特试探和动态预算。这里两组共用 LabelProbe 选择器，以同源、同 QP28、同 qpel MC、同 16 频率和每 P 帧 4 点，按估计局部 SSE 收益除以比特代理排序。该代理用于选标，实际码率来自完整 JM 码流。

| 指标 | 结果 |
| --- | --- |
| 训练 / 验证中位 IoU | 0.133 / 0.128 |
| 验证中位共同位置 | 14.5/64 |
| 验证共现符号一致 / level MAE 中位数 | 100.0% / 0.556 |
| 密集 level 精确相同中位数 | 98.94% |
| T0 / T1 选中位置在对方密集标签归零 | 1.56% / 0.78% |
| T0 / T1 严格回放重算后全帧标签相同的视频 | 0/16 / 0/16 |
| T0 / T1 实际参考相对标签生成参考 Y-MSE | 76.5345 / 18.8598 |

T0/T1 标签分别在固定历史前缀上生成。回放后在实际进入 JM 的参考上重新选标，逐帧记录标签是否变化。实际回放沿其自身更新，因此上述诊断是固定历史参考生成标签后的整段 RD，不能视为在线自洽教师。T1 源辅助整段较 A 改善 +0.068322 dB，末四帧 +0.070158 dB，逐视频均在 +3% 以内，满足 O0 启动 O1 的门槛。
