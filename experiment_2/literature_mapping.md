# E2 literature and code mapping

This is an original simplified latent-domain adaptation, not reproduction of full GNVC-VD, GLVC, ELIC or DCVC. Accessed 2026-11-27.

| Reference | Evidence and implementation map | Reuse and limits |
|---|---|---|
| [GNVC-VD](https://arxiv.org/html/2512.05016v2), §§3.1–3.2, 3.4, Appendix B, Figs 3/8 | Anchor is independent; predictive slices use reconstructed history in analysis/synthesis. Appendix B maps anchor to ELIC [11], inter to DCVC-RT [16], two-step estimation to HEM [24]. | Inspiration only. No verified author source obtained. No VideoDiT refinement/adapters or generator training. Its original input uses VAE encoding; ours starts at saved DiT final latent. |
| [GLVC](https://arxiv.org/abs/2510.09987) | Continuous video tokenizer, unified intra/inter and recurrent memory. | Abstract verified; OpenReview PDF blocked by browser challenge, full training strategy NOT VERIFIED. Recurrent memory NOT RUN; no full reproduction claim. |
| [DCVC-RT](https://github.com/microsoft/DCVC) | Exact reference subtree `DCVC-family/DCVC-RT`, not current root model. `src/layers/layers.py:DepthConvBlock`; `src/models/video_model.py:Encoder, Decoder, FeatureExtractor, HyperEncoder, HyperDecoder, PriorFusion, SpatialPrior, DMC`; `common_model.py` two-step priors; `entropy_models.py:EntropyCoder, BitEstimator, GaussianEncoder`; `utils/stream_helper.py` stream/SPS. | Commit cbdae87a5445114cdc7f48816da63ea80bdeac40, MIT. Read-only reference. RGB patchify/unpatchify/reconstruction heads require replacement with 16-channel latent heads, new trained weights; no pretrained RGB weights reused. QP/module banks not yet ported. |
| [ELIC](https://openaccess.thecvf.com/content/CVPR2022/html/He_ELIC_Efficient_Learned_Image_Compression_With_Unevenly_Grouped_Space-Channel_Contextual_CVPR_2022_paper.html) | Uneven space-channel contextual model motivates later I4; GNVC Appendix B explicitly cites ELIC. | CVF direct access returned 403. Exact ELIC layer sizes not asserted or copied. Current I2/I3 do not implement ELIC context or attention. |
| [DCVC-HEM](https://arxiv.org/abs/2207.05894) | Temporal latent prior and parallel-friendly dual spatial prior motivate P3/P4. DCVC source available under `DCVC-family/DCVC-HEM`. | Not yet ported. No motion search or spatial context in I2/I3. |
| [CompressAI](https://interdigitalinc.github.io/CompressAI/entropy_models.html) | `compressai/entropy_models/entropy_models.py:EntropyBottleneck,GaussianConditional`; `compressai/models/google.py` factorized/hyperprior examples; rANS native backend. | Package 1.2.8; source tag v1.2.8 commit 79e51871e972c517bc528b689ccf15137fcc7785; BSD-3-Clause. API reuse in E2 `codec.py`, no vendored modified source. Original E2 transforms/serialization/training; dynamic CDF buffers resized at checkpoint load. |

GNVC training includes codec and diffusion adapters then pixel fine tuning with frozen backbone; our scope excludes adapters. Frozen Wan VAE may pass gradients in a later E2.3 reconstruction branch. No such branch exists in this smoke implementation.

DCVC-RT C++ rANS setup uses pybind11, C++17, -O3, Python >=3.12. Toolchain available: GCC 13.3, nvcc 12.0; torch runtime CUDA 12.8. CUDA custom inference compilation NOT RUN (toolkit mismatch must be checked first). First prototype uses CompressAI prebuilt CPU rANS, not DCVC CUDA extensions.
