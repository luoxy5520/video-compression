# Code changes

Additive experiment scripts under training_diagnosis preserve historical codec checkpoints. common.py splits existing I3 likelihoods and adds explicit diagnostic quantization modes. audit.py tests weights, gradients, optimizer coverage, symbol rules and actual entropy streams. reconstruction.py bypasses quantization/hyperprior and persists full optimizer/scheduler/RNG state atomically. reconstruction_eval.py uses full5-slice native VAE output, never independently decoded slice videos. pixels.py applies native decoding and historical8-bit BT709 YUV evaluation. R2/R3 reconstruction diagnoses and the same-shape analytical identity witness are now complete.

Resume: shared restore_state resizes dynamic CDF buffers for training checkpoints, matching the deployment loader. Added multi-video seeded sampler and complete resume state; VAE gradient audit with native/full-sequence forward parity and full parameter hash; TP1/TP2 fixed-symbol CDF translation and gated resumable entropy-only fitting. Added relevant regression checks; all five tests passed on113Server. Full FP32 activation checkpointing passed after the original FP32 activation run exceeded available memory; mixed precision was not required. No VAE or historical checkpoints modified.

Increased-budget continuation: pixel_train.py now selects pre-calibrated low/middle/high source checkpoints with source-hash resume protection. continue_training.py supplies bounded dual-GPU queues, complete-result prerequisites, atomic status and append-only command journals. evaluate_pool.py verifies original E1 input SHA and evaluates all18 historical videos, including re-encoded Uniform curves, without test access. Temporal zero-history control retains identical predictor capacity and budget. Added original Wan Apache-2.0 and CompressAI BSD-3-Clause-Clear license texts.

Full evaluation additions: h264_reference.py explicitly round-trips limited BT709 YUV through standard x264/ffmpeg; pixels.py accepts actual decoded H.264 YUV for PSNR-Y rather than a second RGB conversion. evaluate_pool.py persists per-slice main/hyper bytes and validates complete container totals. summarize_pool.py provides measured-support-only comparisons against both Uniform and fresh H.264 curves, effective coverage and unique per-video plots. gpu_profile.py measures actual GPU-start P2/P3 and H.264 pipelines with repeated samples.

dataset_audit.py verifies all42 declared legal training and18 historical development tensor hashes/shapes/group separation. audit_extended_checkpoints.py performs CPU-only real-stream checks of completed20k checkpoints and explicitly does not infer pixel quality. finalize_queue.py waits on actual dual-lane completion before profiling, summaries and artifact hashes. build_report.py answers the experiment questions from measured full-pool artifacts and retains review-pending state and optional NOT RUN items. README and experiment_status.json distinguish trained, evaluated, running and queued stages.
