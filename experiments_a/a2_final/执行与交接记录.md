# 实际执行与交接记录

## 是否训练过
没有使用真实压缩标签训练，也没有生成已训练权重或真实精度指标。真实 oracle 标签尚未完成。此前运行的是特征完整性检查和合成输入前向/反向测试，不能当作训练结果。

## 已执行
1. utility_scripts/decode_final.py：加载4份 solver final_latent，仅加载VAE，输出各样本final_raw.yuv及a0_manifest.json；日志位于服务器仓库a0_decode.log。
2. utility_scripts/build_final_pairs.py：构建a2_final_pairs.json；16条中间特征记录对应4个唯一最终目标，附目标YUV SHA256。
3. utility_scripts/a2_final_mode.py --config configs/exp_a2_final.yaml --check-features：读取真实latent、检查形状/有限值，验证8条训练记录、8条测试记录的分组和步骤完整性；未加载标签。
4. 通过临时Python命令调用FinalModeHead，检查合成输入前向输出、不同步骤条件、有限梯度及已知混淆矩阵指标。未保存权重；未执行train.sh/test.sh。

## 模型和计划中的真实训练
输入 [1,16,5,60,104] clean latent，step/20 通过MLP嵌入到特征通道；共享Conv3D头插值输出 [1,2,16,30,52]。交叉熵，Adam，lr=0.001，30 epochs，channels=32。当前仅预测模式，未使用hidden，尚无MV/residual训练。
红车两个seed（样本0000/0001）训练，蓝球两个seed（0002/0003）测试，同一样本四步不跨集合。4个视频只用于pilot，不能支持泛化结论。

真实标签就绪后按README执行check-labels、train.sh和test.sh；模型权重head.pt、分步骤metrics_by_step.json、每样本每步骤预测NPZ届时才会生成。
